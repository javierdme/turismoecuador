Proyecto: Sitio Web de Fotografía Personal y Turismo en Ecuador
Entrega: Semana 4 - Diseño Responsive y Estilos

Integrantes:
- Javier Mantilla

Descripción:
Portafolio web desarrollado con HTML5 y CSS3 para exhibir fotografías turísticas de las cuatro regiones del Ecuador (Costa, Sierra, Oriente y Galápagos). 
En esta versión se implementó CSS Grid y Flexbox para estructurar las galerías y perfiles. 
El sitio es completamente responsive, adaptándose a pantallas de celular, tablet y escritorio mediante el uso de media queries. 
Se integraron variables CSS para mantener una paleta de colores coherente, Google Fonts para la tipografía y FontAwesome para la iconografía en la nueva sección de "Servicios".
