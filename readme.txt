Proyecto: Sitio Web de Fotografía Personal y Turismo en Ecuador
Entrega: Semana 4 - Diseño Responsive y Estilos

Integrantes:
- Javier Mantilla

Descripción:
Portafolio web fotográfico capturada a través de un dispositivo móvil, es un sitio interactivo diseñado para promover el turismo en las cuatro regiones del Ecuador: Costa, Sierra, Oriente y Galápagos. 
Desarrollado con HTML5 semántico y CSS3 moderno (Flexbox y CSS Grid), el sitio ofrece una experiencia 100% adaptable (responsive) para dispositivos móviles, tablets y escritorio.
